# B-504 pilot: sheet layout mockups

Layout mockups for the updated B-504 MSE/GRS worksheets, 34 × 22 in (SVG, 50 px per in). Each one shows where the
drawing, table and note blocks go and what they hold; orange blocks are new or reworked. They aren't to scale: the
sheets are drafted in MicroStation from these and from the content files one folder up.

| B-504-B2 | B-504-B2-truncated-soil.svg | A2–F2, L2–N2 | truncated-base-sections.md |

The design equations are on the sheets that compute: E1–E9 (external) and R1–R5 (barrier) on H1, I1–I10 (internal)
on H2, V1–V6 on V0 and A1–A5 on B4, each with its AASHTO or Web Doc 326 reference. The full lists, with what each
symbol means, are in the content files ("Equations" sections).

Table values on the mockups are a sample of rows taken from the content files' full tables. Items marked
[Decide …] or [Verify …] are the open decisions listed in those files.
